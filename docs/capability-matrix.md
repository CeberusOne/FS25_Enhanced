## Verification notes

- **Engine Lighting (cat 11):** all listed Gen-1 lighting setters/getters have dedicated function pages.
- **Engine Rendering (cat 22):** `setShadowFocusBox` (fn=641), `setFastShadowUpdate` (fn=633) confirmed. Distance-coeff / foliage-shadow names are **not** listed under Rendering or Foliage cat 6.
- **Distance coeffs & global shadow quality:** exact engine call names appear in **SettingsModel** LuaDoc source (`add*Setting` writers/readers). GDN site search for `setViewDistanceCoeff` currently surfaces FS22 SettingsModel only; FS25 SettingsModel class page **does** contain the symbols (verified by fetch).
- **Engine Foliage (cat 6):** only bending APIs; `setAllowFoliageShadows` is **not** on this category page (documented via SettingsModel).
- **Blockers:** none for public LuaDoc fetches (no login wall on documentation_scripting_fs25.php). Search index incomplete for some FS25 engine free-functions.
